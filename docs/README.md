# Object Sight Documentation

This folder contains the learning notes and technical decisions behind Object Sight.

## Documents

- [Stack Decisions](./stack-decisions.md) — why Python, OpenCV, and YOLO were chosen for this experiment.
- [Learning Path](./learning-path.md) — the order in which the project should grow so each step teaches one clear computer-vision concept.

## Documentation Goal

Object Sight is a self-directed learning project. The documentation is meant to capture not only **what** the project uses, but **why** each technology is present and what responsibility it owns in the pipeline.

The core idea is to avoid treating the stack as magic. Every tool should have a clear purpose, and unnecessary tools should stay out until the project actually needs them.
